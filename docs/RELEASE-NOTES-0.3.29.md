# DiPlay v0.3.29 — 跟随系统日夜模式优先采用时间窗口以规避车机常夜上报

## 更新内容

### 1. 跟随系统日夜模式优先采用时间窗口以规避车机常夜上报
- **彻底解决部分车机系统日夜状态卡死常夜导致时间窗口无法生效的问题**：
  - 部分老款安卓车机或第三方刷机 ROM 底层系统日夜状态上报异常，全天候恒定上报夜间状态（`systemNight = true`）；
  - 此前版本中应用主题的时间窗口仅在系统未上报状态（`systemNight == null`）时作为回退机制生效，导致在这类车机上开启时间窗口后依然无法切换至浅色模式；
  - 本次更新重构了日夜状态判定逻辑：在「跟随 Android 系统」模式下，只要开启「使用时间判断」开关，一律优先以设定好的夜间起止时间窗口判定应用主题，彻底摆脱车机异常上报的干扰；
  - 关闭「使用时间判断」开关时，系统上报状态完全保持原生透传；
  - 调整主界面边界检查定时任务，开启时间窗口后不论车机当前是否上报日夜状态均装载定时器，确保到达时间边界时精准自动切换；
  - 同步更新英语、阿拉伯语、西班牙语、俄语、乌克兰语、简体中文、繁体中文等 7 种语言的设置文案与说明。
