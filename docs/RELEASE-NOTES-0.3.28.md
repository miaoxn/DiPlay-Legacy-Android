# DiPlay v0.3.28 — 跟随系统日夜模式支持自定义深色时间窗口起止时间

## 更新内容

### 1. 跟随系统日夜模式支持自定义深色时间窗口起止时间
- **时间窗口起止时间自由设定**：
  - 此前「跟随系统」的本地时间回退采用固定的 18:30–06:00 时间段，无法适应不同季节日照时长或不同车主的作息习惯；
  - 在「设置 → 显示」的时间回退开关下方新增「夜间开始」与「夜间结束」时间选择项，默认分别为 18:30 与 06:00；
  - 点击时间选择项弹出 24 小时制时间选择器，与 CarPlay 计划夜间外观保持一致的防呆逻辑（起止时间相同视为全天浅色，选择相同时提示拒绝）；
  - 修改后主界面立即响应重算主题状态，生命周期感知的定时检查任务自动对齐新的时间边界，车机投屏端通过现有轮询机制即刻生效；
  - 完整适配英语、阿拉伯语、西班牙语、俄语、乌克兰语、简体中文、繁体中文等 7 种语言国际化文案。

### 2. 测试套件与开关控件单例匹配修复
- **单测控件匹配容错**：
  - 修复 `NightModeSettingsTest` 中开关与时间控件匹配在显示设置卡片存在多组时间选择器时出现的单例断言异常，确保单元测试套件持续健壮通过。

## 验证

- 版本 `0.3.28` / `versionCode 148`，包名 `com.shihab.diplay`，最低兼容 Android 4.2（API 17）。
- 全量自动化测试（含 `AppThemeModeTest`、`NightModeSettingsTest` 等单元测试）、各模块 Lint 静态检查及各应用变体构建验证全部通过。
