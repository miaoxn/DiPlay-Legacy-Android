# 亿咖通 E01 / 449 原厂蓝牙

这是本地已实测 APK 补丁的源码移植。用户已确认原补丁在车上可用；本次源码生成的 APK 仍需安装回归，不能把原型测试等同于本提交实测。

## 使用

在 **高级 → 亿咖通原厂蓝牙（实验性）** 中：

1. 在原厂设置中开启蓝牙并配对 iPhone，停止 DiPlay 的 CarPlay 会话。
2. 检测补丁与服务，确认 Root、设备和固件匹配。
3. 已在本车验证过补丁后，选择“安装系统蓝牙补丁”。如果已有匹配补丁，安装器保留原厂备份并检查状态，不覆盖备份。
4. 从“原厂已配对的 iPhone”选择手机，然后开启“使用原厂 GOC 蓝牙”。
5. 沿用现有车机热点设置连接 CarPlay。选项对下次连接生效，不自动中断当前会话。

关闭选项恢复应用原有蓝牙路由；退出或卸载应用不会撤销系统补丁。
恢复系统文件请使用“恢复原厂蓝牙”。操作均需完整停止会话，包括连接中和停止中。

本次移植提供系统安装与恢复，不新增临时监督或自动刷写流程。

## 支持与实现

仅支持 `xea406m`、API22 及以下准确哈希组合：

- 原厂：`52596a2ba3e1be85dc09efd20290b2d6b36aef9e569acd1d86014bcb991fe15e`
- 补丁：`882afd622fe0d7a154e4cf0531d122c3fc54ba87c93cf47f90db258131502c0f`

`GocFirmware` 从本机 `/system/bin/gocsdk` 生成候选，核对长度、原始字节与完整输入/输出哈希。
PR 不分发完整厂商二进制。两处编辑来源于本地 449 原厂衍生补丁：SPP 启用开关和带 iAP2 UUID 的请求构造函数。
应用继续使用既有认证和热点链路；补丁不提供认证资产。

`FactoryDevices` 使用 449 的 `INfCommandBluetooth` Binder ABI：注册/注销回调 2/3、请求列表 11、本机地址 14；配对列表回调 6。
查询核对接口 descriptor、固件哈希，并使用单飞线程和总超时。保留进程期绑定，避免最后解绑关闭厂商服务。
`EcarxGocBluetoothAdapter` 连接 RESERVED `goc_spp`，先写入 12 字节无冒号大写手机地址，再传输 iAP2。
不反射创建 Android BluetoothDevice，不调用 Android 蓝牙 enable，不把已配对当作已连接。
选择 GOC 时不自动回落 USB 或 Android，也不因退出 CarPlay 关闭原厂电话/媒体蓝牙。

## 安装与恢复

安装脚本检查 Root、型号、SDK、哈希、运行服务、外部 GOC 进程、挂载状态及已知 verity 配置。
原厂备份保存在 `/data/local/goc449-system-backup/gocsdk.stock`，只在确认原厂哈希时创建。
候选在同分区 staging 后同步并原子替换，保留权限/属主/可读取的 SELinux 上下文；失败尝试恢复安装前字节。
原来只读的 system 分区在结束时恢复只读。

恢复允许服务已停止。原厂字节已恢复但服务健康检查失败时保留原厂字节，并关闭应用 GOC 路由；不会换回补丁。
Root 操作超过三分钟时 UI 报告仍在等待，后台仍持有操作锁直至进程退出；不把超时当作取消或成功。
重启应用后操作以系统状态和磁盘锁为准。发现遗留锁/staging 必须检查实际进程，不能盲删。
掉电、内核崩溃和被强杀不保证执行 shell 清理；冷启动恢复仍需实车回归。

应用无法打开时，若备份及保存的脚本可用，可通过已授权 ADB 执行：

```sh
adb shell "su -c 'sh /data/local/goc449-system-backup/manage-system-goc.sh rollback'"
```

## 验证

- `python3 scripts/tests/test_goc449_transaction.py`：使用合成字节和隔离进程/文件系统，覆盖安装、重复安装、停止服务回滚、启动失败恢复、原厂恢复后启动失败、坏输入和已有 staging 保留。不会挂载或运行固件。
- `GocBufferedDuplexTest`：超时、部分读取、EOF、关闭唤醒、2.1 MB 背压传输、IOException。
- 本地真实原厂文件生成结果与已实测候选逐字节相同：长度 2,804,800，两处允许区间内共 90 字节变化；原始文件未加入仓库。
- `GocFirmwareTest`：设备、输入和地址拒绝，以及会话/维护互斥。
- `GocRouteTest`：选择不支持的 GOC 后不回落到 Android；厂商列表清洗去重。
- 完整单测/lint/debug 构建使用仓库 `AGENTS.md` 中命令。

实车回归重点：源码 APK 的配对列表、连接/重连、通话和音乐、安装和恢复状态，以及恢复后的冷启动。
设计背景见方案 PR #369；原补丁与源码 APK 的测试记录应分开维护。
