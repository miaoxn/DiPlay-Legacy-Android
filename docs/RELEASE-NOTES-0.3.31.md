# DiPlay v0.3.31 — 压低音乐播报结束后平滑渐入恢复音量以避免突兀满声

## 更新内容

### 1. 压低音乐播报结束平滑渐入恢复机制（Issue IKVN7Z）
- **消除导航/语音播报结束瞬间音乐直接跳跃满声的突兀听感**：
  - 在高级设置中开启「压低音乐」后，此前版本在播报结束后需等待约 1.5 秒硬性延迟，且音量瞬间直接跳回目标满值，存在明显阶跃感；
  - 本次更新将播报结束释放窗口从 1500ms 缩短至 200ms，在播报结束后迅速起音；
  - 引入分层渐进升音（Volume Ramp）恢复机制：由低至高按阶梯步进平滑爬升至原音量，听感自然柔和；
  - 包含防抖与状态机保护（`ramp_guard`）：有效处理短播报连发、焦点瞬时抖动抢占及播报被打断等边界场景；
  - 补齐正常起坡、连续连发打断、焦点丢失静音与资源销毁等全量单元测试覆盖。

## 验证

- 版本 `0.3.31` / `versionCode 151`，包名 `com.shihab.diplay`，最低兼容 Android 4.2（API 17）。
- 全量自动化测试（含 `AudioFocusAutoYieldTest` 等单元测试）、各模块 Lint 静态检查及各应用变体构建验证全部通过。
