# DiPlay v0.3.24 — 车内投屏设置菜单与侧边快捷栏适配日夜浅色主题

## 更新内容

### 1. 车内投屏设置菜单（三指滑动）与分类栏全面适配浅色主题
- **菜单背景与组件配色联动应用主题**：
  - 过去在应用主题切换为浅色模式后，CarPlay 运行中通过三指滑动打开的设置菜单及其左侧分类导航栏（Category Rail）仍固定为深色常量配色；
  - 重构 `CarPlayHostActivity` 中的菜单调色板解析逻辑，统一调用 `SettingsTheme.forSurface(isOverlay = true, night = hostAppNight)` 动态获取当前主题色盘；
  - 浅色模式下，菜单背景、卡片表面、按钮底色、边框及主次文本自动刷新为浅色系样式；危险操作按钮（`MENU_DANGER`）与纯黑视频流背景保持独立对比度，确保易读性；
  - 设置菜单每次打开时均自动采用最新主题，打开过程中若发生系统日夜模式变更，将平滑等待下次打开时刷新，避免打断当前未保存的配置项编辑。

### 2. CarPlay 投屏侧边快捷栏（时钟与电量）实时响应日夜模式切换
- **侧边快捷面板动态重绘**：
  - CarPlay 投屏界面侧边栏中的大字号时钟（`TextClock`）与电量里程信息（`sidePanelBattery`）同步接入应用主题系统；
  - 新增 `paintSidePanel()` 轻量刷新机制，在车机系统日夜模式切换或配置变更回调（`onConfigurationChanged`）时直接重绘背景与文字色彩，无需重建 View 即可实时生效，绝不影响正在进行的投屏画面与布局。
