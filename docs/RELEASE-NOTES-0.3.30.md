# DiPlay v0.3.30 — USB 共享网络断网宽限期重验以避免瞬时抖动引发频繁断连

## 更新内容

### 1. 随身 WiFi / USB 共享网络瞬时闪断重验机制（Issue IKU53B）
- **平滑消除随身 WiFi 瞬时抖动导致的频繁断连重连循环**：
  - 用户实测反馈随身 WiFi（通过 RNDIS/ECM 提供 USB 网络共享）在行车途中可能短暂掉落并重建 `Network` 对象；
  - 此时底层局域网与车机 IP 地址均未改变，此前版本在接收到首次 `onLost` 时立即强制拆毁并重连 CarPlay 会话，导致短时间内发生多达十余次断连；
  - 本次更新引入 3 秒宽限期重验机制：在选定的网络连接丢失后，开启 3 秒宽限期，若相同网络接口、主机 IP 及地址集的链接在宽限期内重新出现，则自动接管替换的新 Network 对象并无缝保持当前会话；
  - 仅当网络真正持续断开超时，或重连的是不同局域网链接时，才触发平滑重置；
  - 包含针对瞬时闪断自愈、超时重启及异网替换等完整单元测试覆盖。
