# DiPlay v0.3.32 — 连接链路自检指示灯、实测解码分级与多手机轮询管理

## 更新内容

### 1. 连接链路自检状态指示灯与反馈诊断（IKTCRS）
- **有线/无线链路状态直观呈现**：
  - 连接面板新增链路自检状态灯（灰/绿/黄/红圆点）与实时等待进度行，与 `[n/16]` / `[n/12]` 链路日志严格对齐；
  - 由纯状态机 `ChainStageTracker` 驱动，异常中断时指示灯变红并提供针对性的引导排查建议，多语言全面适配。

### 2. 实测解码性能统计与可解释硬件分级（IKT54J G）
- **性能基准与档位建议**：
  - 运行时收集 5 秒活动窗口的实测帧率中位数（rx fps median）与解码延迟 p90 指标；
  - 硬件信息卡片展示实测数据与命中规则，综合静态参数与动态解码指标给出明确、可解释的性能档位建议与推荐配置。

### 3. 多手机轮询、蓝牙来源与 Wi-Fi 前台拉起优化
- **蓝牙来源自由切换**：支持选择车机内置蓝牙、外置 USB 蓝牙适配器或自动选择；
- **多机列表与别名管理**：支持保存多台 iPhone 别名备注、手动切换首选设备与自动循环寻呼轮询；
- **Wi-Fi 连通置顶前台**：检测到车机或手机 Wi-Fi 连通时自动将 DiPlay 拉至前台，解决开机被第三方桌面挤压至后台的问题；
- **车机蓝牙断开优化**：优化无线连接建立后断开原车蓝牙电话通道的执行逻辑，断开更彻底、挂断更干净。

## 验证

- 版本 `0.3.32` / `versionCode 152`，包名 `com.shihab.diplay`，最低兼容 Android 4.2（API 17）。
- 全量自动化测试（含 `ChainStageTrackerTest`、`MeasuredDecodeStatsTest`、`KnownPhonesPreferenceTest`、`WifiForegroundTriggerTest`）、各模块 Lint 静态检查及各应用变体构建验证全部通过。
